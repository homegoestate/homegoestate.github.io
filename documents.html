買賣簽約自然人買方新成屋／中古屋一般買賣查看清單

請準備

  1. 雙證件正本身分證＋健保卡
  2. 個人便章
  3. 簽約金原則為成交價 10%，實際依契約約定
  4. 貸款所需財力證明如薪轉、扣繳憑單或其他銀行要求資料
如有共同買受人，原則上每位買方都需準備證件與印章。
買賣簽約自然人賣方新成屋／中古屋一般買賣查看清單

請準備

  1. 身分證正本
  2. 個人便章
  3. 土地、建物權狀正本
  4. 印鑑章
  5. 印鑑證明用途註明「不動產登記用」
如有抵押貸款，請同步告知原貸款銀行及聯繫窗口。
公司案件公司名義買賣買方公司／賣方公司／建設公司查看清單

公司買方

  1. 負責人身分證正反面影本
  2. 公司變更登記事項表正本或影本
  3. 公司大小章簽約時便章足矣

公司賣方／建設公司

  1. 負責人身分證正本或影本
  2. 公司變更登記事項表
  3. 土地、建物權狀正本
  4. 公司大小章印鑑章可先用於契約，簽約時便章足矣
財產移轉夫妻贈與贈與人與受贈人均需準備查看清單

請準備

  1. 雙方身分證正本
  2. 雙方個人便章
  3. 土地、建物權狀正本贈與方提供
  4. 印鑑章贈與方提供
  5. 印鑑證明贈與方申請，用途註明「不動產登記用」
應負擔費用可能包含代書費、契稅、印花稅及銀行借款人變更費用等，請先個案確認。
抵押設定私人設定借款人／金主查看清單

借款人

  1. 身分證正本或影本
  2. 土地、建物權狀正本
  3. 印鑑證明用途註明「不動產登記用」
  4. 印鑑章

金主

  1. 身分證正本或影本
  2. 便章
  3. 本票、借據
建物登記建物第一次登記又稱建物保存登記查看清單

請準備

  1. 使用執照正本
  2. 使用執照竣工平面圖正本
  3. 起造人身分證影本公司戶另附公司變更登記事項表影本及負責人身分證正反面影本
  4. 便章公司戶使用公司大小章便章
土地案件土地分割土地及共有土地分割基本資料查看清單

請準備

  1. 所有權人身分證影本
  2. 土地權狀正本
  3. 土地分割計畫用印後歸還
  4. 原設定銀行聯繫窗口土地如有貸款
  5. 便章一枚
土地案件共有物分割共有關係調整與登記查看清單

請準備

  1. 所有權人身分證影本
  2. 土地權狀正本
  3. 土地分割計畫用印後歸還
  4. 原設定銀行聯繫窗口土地如有貸款
  5. 印鑑章
  6. 印鑑證明 1 份用途註明「共有物分割」

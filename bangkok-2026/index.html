已登記團員

給主揪｜如何讓 14 人登記同步？

GitHub Pages 只有靜態網頁，無法自行建立跨裝置共享資料庫。附帶的 shared-backend/Code.gs 可部署成 Google Apps Script，資料存於你自有的 Google 試算表。

  1. 依 README 建立 Google Apps Script，執行一次 setup() 產生 14 組登記碼。
  2. 部署「網頁應用程式」，複製 /exec 網址到網站的 config.js。
  3. 把網站推上 GitHub Pages，將每個編號及個人登記碼分別交給團員。
  4. 團員按「儲存我的登記」後會收到同步成功或錯誤回覆；列表可重新整理確認。

這是方便朋友分組的輕量機制，並非正式登入系統。請勿用來收集私人或專業敏感資料，且不要把登記碼放進公開 GitHub。

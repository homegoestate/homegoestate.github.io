# 台南房產地圖 V5 維護說明

正式入口：<https://homegoestate.github.io/tainan-map/>。首頁主按鈕、首頁地圖區塊及共用選單均可進入；地圖頁可回官網。

## 檔案位置

| 調整內容 | GitHub 檔案 |
|---|---|
| 首頁入口的文字與區塊 | `index.html` |
| 全站選單及頁尾入口 | `app.js` |
| 首頁及全站手機版樣式 | `styles.css` |
| 地圖頁文字與控制項 | `tainan-map/index.html` |
| 地圖、分類、排序、比較、成交明細 | `tainan-map/app.js` |
| 地圖手機版及外觀 | `tainan-map/styles.css` |
| 分批載入、檢查資料完整性、錯誤重試 | `tainan-map/data-loader.js` |
| 版本、原始 V5 雜湊及每個資料檔案索引 | `tainan-map/data-manifest.json` |
| 地方生活內容 | `tainan-map/life-data.js` |
| 回饋草稿與正式回饋入口 | `tainan-map/feedback.js` |

資料檔案由核對過的 V5 `dist/data.js` 分拆產生，不手改房價。`data/` 的檔名帶內容雜湊，更新資料時應一併產生摘要、各區明細與 manifest，再完整測試後發布。

## 這次資料版本

- 統計快照：2026-11-02。歷史下限為 2012-08-01（101 年 8 月 1 日）；最新取得交易日為 2026-10-16，快照日期不等於交易日期。
- 3,813 項社區名冊、1,388 項有歷史住宅價格參考、1,157 項有核對過的使照登載戶數。
- 41,957 筆已匹配原交易明細完整保留；超出統計期間、排除條件的明細仍留供查核，並未全部計入均價。
- 住宅／套房／一般 1 房／2、3、4、5 房以上／店面及用途或格局待核分開。歷史均價不是即時行情；1–4 筆標為少量樣本。
- 使照戶數不是現況住戶普查；屋齡是成交樣本的完工日期推算。無資料不以鄰近平均補值。
- 地圖保留 37 行政區；有名冊的 33 區各有一份按需載入明細。未收錄不等於不存在。

來源與計算方法在地圖「資料與方法」公開顯示。官方實價入口為 <https://lvr.land.moi.gov.tw/>，使用者可先複製完整門牌後查詢；未宣稱官方網站會自動帶入社區。

## 手機與資料載入

現代瀏覽器先下載約 1.45 MB 壓縮摘要，點開成交明細才下載所屬行政區檔案；不會在首頁下載整套地圖資料。較舊瀏覽器可自動改讀 JSON。載入失敗顯示重試，不會把錯誤當成零成交。手機可直接垂直滑動地圖區域，以行政區選單、點選及縮放按鈕探索。

## 回饋與訪客數

公開版不收集訪客事件、不顯示累積訪客數。不能把下載次數、測試次數或社區數量當成訪客數。回饋可先複製／下載，再由使用者自行送到安心城既有正式回饋入口；本頁不會假裝已送出給團隊。

## 發布與回復

GitHub Pages 來源為 `main` 的根目錄。保留原官網服務、文件、安心城與預約流程。本次發布前已另存完整 108 檔 ZIP、SHA-256 清單及公開檔案比對。

回復時以本次發布提交做一般 `git revert`，先檢查是否有後續他人變更；不要重設整個主分支或將舊備份覆蓋新資料。備份與完整 QA 報告留存在本機交付記錄，沒有上傳客戶資料、測試記錄或憑證。
